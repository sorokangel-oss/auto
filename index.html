네이버 블로그 자동 포스팅 프로그램

Claude로 글(제목·본문·태그)을 생성하고, Playwright로 네이버 블로그에 자동으로 로그인·발행하는 오픈소스 파이썬 프로그램입니다.

Python Playwright Claude API APScheduler

주요 기능

  • 주제만 입력하면 Claude가 제목·본문·태그를 생성
  • SmartEditor ONE을 자동 조작해 실제로 글을 발행
  • 세션 저장으로 한 번 로그인 후 재로그인 없이 반복 사용
  • APScheduler로 매일 정해진 시각에 자동 발행
  • 별도 API 결제 없이 기존 Claude 구독 인증 재사용 가능

빠른 시작

git clone https://github.com/sorokangel-oss/auto.git
cd auto
pip install -r requirements.txt
playwright install chromium
cp .env.example .env   # 네이버/Claude 인증 정보 입력
python main.py login
python main.py post-now --topic "오늘의 추천 주제"
